# Pulse MVP Requirements

## Purpose

Pulse is an internal application for reporting the operational status of services owned by company teams.

## Service

Each service must have:

- ID
- Name
- Description
- Owner
- Status
- Created timestamp
- Updated timestamp

## Valid Statuses

- Operational
- Degraded
- Outage
- Maintenance

## Required Operations

Users must be able to:

- View services
- View an individual service
- Create a service
- Update a service
- Delete a service
- Change a service's status
